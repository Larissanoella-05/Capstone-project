# Usability test: report a fault

Ask 3 to 5 people to do this on their own phone. Do not help them. Watch, and write down what you see.

**Before you start.** Tell them: "You have no electricity. Report it with this app. Think out loud." Give them only the web address. Start the timer when they open the page.
